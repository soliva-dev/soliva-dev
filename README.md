## 🚀 Proyecto destacado

### 🗓️ [Turnerito App](https://github.com/turneritoapp)

**Sistema multi-tenant de gestión y reserva de turnos para negocios de servicios.**

Turnerito permite a negocios como barberías, peluquerías, centros de estética y profesionales independientes gestionar sus reservas, especialistas, servicios y disponibilidad mediante una plataforma web. El sistema también incorpora verificación por WhatsApp, recordatorios automáticos, gestión de pagos, paneles administrativos, control de acceso por roles y automatizaciones.
