# 👋 ¡Hola! Soy Samuel Oliva

¡Bienvenido a mi perfil de GitHub!

Soy desarrollador backend en formación continua, con especial interés en **PHP, bases de datos y desarrollo web**. Me enfoco en seguir construyendo soluciones eficientes, mantener buenas prácticas de programación y ampliar mis conocimientos en el ecosistema web.

## 👨‍💻 Sobre mí

Actualmente trabajo en [Legajos Online](https://legajosonline.com) ([LOL](https://github.com/Legajos-Online)), un sistema de gestión de recursos humanos para empresas, donde me desempeño desde junio de 2024.

Cuento con conocimientos en desarrollo backend con **PHP**, manejo de **bases de datos relacionales** y desarrollo web. Además, finalicé mi formación en **Desarrollo Web Full Stack**, incorporando conocimientos tanto del lado del servidor como del cliente.

Me interesa especialmente el desarrollo de sistemas, la automatización de tareas y la creación de soluciones que aporten eficiencia a los procesos de trabajo.

También me interesa colaborar en **proyectos open source** relacionados con el desarrollo backend, el desarrollo web y las herramientas que forman parte de este ecosistema.
